# ⚠ グループ構文の注意（2026-08-24 追記・実際に踏んだ罠）
#   robots.txt は「最も具体的に一致した User-agent グループ 1 つだけ」が適用され、
#   `*` グループと名前付きグループは **結合されない**（Google 公式仕様・RFC 9309）。
#   下の Googlebot 以下 7 つの名前付きグループがある限り、`*` に書いた Disallow は
#   それらの bot に一切効かない。**Disallow を足すときは 8 グループすべてに書くこと。**

# ===== 汎用設定（全クローラー） =====
User-agent: *
Allow: /
# Cloudflare のメールアドレス難読化が mailto: を
# /cdn-cgi/l/email-protection#<token> に置換する（index / about / careers / privacy の
# 4 ページから参照）。クローラがこれを辿ると 404 を返し、Search Console が
# 「見つかりませんでした（404）」としてインデックス未登録要因に計上する
# （2026-08-24 実測。sitemap 掲載 11 URL はすべて 200 で、404 はこの 1 経路のみ）。
# 実害は無いがノイズなので巡回対象から外す。
# 範囲を /cdn-cgi/l/ に絞るのは、復号スクリプト /cdn-cgi/scripts/.../email-decode.min.js を
# クロール可能なまま残すため（ここまで塞ぐと Googlebot のレンダリングで復号されず
# メールアドレスが [email protected] のまま索引される）。
Disallow: /cdn-cgi/l/
