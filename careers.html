AIと業務改善で、
仕事の"当たり前"を変える。

IT・業務改善スタッフ 募集中｜正社員

現役の在宅医が創業し、自社の医療現場の課題を自分たちで解いている会社です。

掲載日：2026年7月2日／最終更新日：2026年8月13日／掲載期限：2026年11月30日（募集状況により延長・終了する場合があります）

MDX株式会社では、AIツール（Claude Code / Gemini）を活用しながら、日々の業務をより効率的で再現性のあるものへと変えていく取り組みを行っています。

多くの現場では、非効率な作業や属人化した業務がまだ数多く残っています。私たちはそれらを一つひとつ整理し、AIやITツールを活用することで、よりスムーズで持続可能な仕組みに変えていくことを目指しています。

そのために必要なのは、「特別な技術」だけではなく、目の前の業務をより良くしたいという視点と、実際に手を動かして改善していく力です。

AI 未経験 OK

AIツールを使ったことがなくても大丈夫？

はい。AIツールの使用経験は応募条件にありません。業務ごとのマニュアルを整備しており、実務の中で使いながら習得できます。

コードは必須ではない

コードが書けないと厳しい？

全員に必須ではありません。業務の整理・標準化を中心に進めることもできます（IT業界での実務経験は応募条件です・年数不問）。

常駐なし

客先常駐や派遣はある？

ありません。労働者派遣事業・客先常駐（SES）は行っておらず、就業場所は横浜市都筑区の自社オフィスのみです。

ほかの疑問はよくある質問にまとめています。

この仕事でやること

本ポジションでは、AIツールやITを活用しながら、業務の整理・改善・標準化を進めていただきます。単に作業をこなすのではなく、「どうすればもっと良くなるか」を考えながら仕組みを作っていく役割です。

  • Claude Code / Gemini を活用した業務改善・効率化
  • 業務フローの整理・可視化
  • マニュアルの作成・更新
  • データ整理・情報の構造化
  • ITツールの導入・運用サポート
  • 社内の業務に関する課題抽出と改善提案
  • 適性・ご希望に応じて、Python 等を用いた自動化ツールの開発・保守

どこまで手を動かすかは固定していません。業務の整理・標準化に寄せることも、自動化ツールや自社プロダクトの実装まで担うこともできる、「整理する側」と「作る側」のどちらにも寄せられるポジションです。

AIツール（Claude Code / Gemini）は会社が用意し、全スタッフが日常業務で使用しています。一部の担当者だけが試しているのではなく、開発も業務改善も日々この環境の上で動いています。新しいツールややり方を試しやすく、Claude Code の経験がなくても実務の中で使いながら習得できます（業務ごとのマニュアルを整備しています）。

道具は、代表と同じものを使います

Claude Code をはじめとする AI エージェントを主役に据えた環境で、コードを書く場面も、業務を整理する場面も進めていきます。この環境は代表と同等のものをそのまま使います——役職や職種に応じて機能を絞った「スタッフ用の縮小版」を配ることはしていません。同じ道具で、同じやり方で仕事をします。

AI エージェントに任せる範囲は日々広がっていて、「AI に指示を出して仕事を進める」こと自体が業務の中心になりつつあります。使いこなし方は、実務の中で身につけていける環境です。

入社後の教育体制

「いきなり一人で任される」ことはありません。メンターがつく体制を取っており、オンライン研修と OJT の両方で業務を覚えていきます。

  • メンター制相談先が決まっているので、分からないことを抱え込まずに進められます
  • オンライン研修基礎的な知識は、自分のペースで学べる形で用意しています
  • OJT実際の業務に入りながら、手を動かして覚えていきます
  • マニュアル業務ごとの手順書が整備されており、AI からも参照できます

最初からすべてをお任せするのではなく、段階的に担当の範囲を広げていきます。AIツールの使い方も、この流れの中で実務を通して身につけられます。

引き継ぎは「人に聞く」より先に「検索できる」

属人化を減らすため、業務の手順や判断の経緯をテキストで残し、AI から検索・参照できる形で共有しています。前任者の記憶に頼らず、必要な情報に自分でたどり着ける状態を標準にしています。

  • 業務ごとのマニュアル手順を文書化し、変わったらその場で更新します
  • 判断の記録なぜそう決めたかを残し、後から辿れるようにします
  • 共通のルール安全に関わる決まりは、文書ではなく仕組みで守ります
  • AI からの参照これらを Claude Code / Gemini から引ける形で置いています

技術環境と、私たちが作っているもの

当社は受託した案件だけでなく、自社で企画・運営しているプロダクトを持っています。業界特化ポータル群や社内向けの業務自動化ツールは実際に本番稼働しており、自分たちで使い続けながら改善しています。中小企業向けの統合労務SaaS（romubase）は現在開発中で、これから立ち上げていくフェーズです。稼働中プロダクトの改善と、0→1 の立ち上げの両方があります。

主に扱う技術

Python / TypeScript / Next.js / React Native（Expo）/ Supabase / Playwright / GitHub Actions / 各種 API 連携（Gmail・Search Console・Stripe ほか）／静的サイトジェネレーター（内製）

設計で大事にしていること

送信・確定などの重要な操作は必ず人間が最終判断するゲートを残す、認証情報を自動化ツールに渡さない、機微情報のフィルタは fail-close にする——といった安全側に倒す設計を標準にしています。CI 上での自動チェックや pre-commit ガードで、ルールを文書ではなく仕組みとして担保しています。
